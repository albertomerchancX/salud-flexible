Este sitio es una demostración académica. No procesa pagos reales, no valida documentos y no envía pedidos a personas reales. Los datos de prueba se guardan únicamente en este navegador.

Cómo funciona

1. El ejecutivo elige un menú y programa la entrega.

2. El cocinero prepara el pedido.

3. El repartidor realiza la entrega.

4. Salud Flexible registra una distribución económica simulada.
